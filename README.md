
# 🍴 SAVORA — Recipe Gallery

SAVORA adalah website galeri resep yang dibuat untuk menampilkan berbagai macam resep makanan dari berbagai negara secara menarik, sederhana, dan mudah digunakan.

Website ini dirancang dengan tampilan yang elegan dan responsif sehingga pengguna dapat menjelajahi berbagai resep, melihat kategori makanan, serta menemukan resep yang sesuai dengan keinginan mereka.

## ✨ Fitur

- 🏠 **Home** — Menampilkan informasi dan rekomendasi resep.
- 🍽️ **Recipe Gallery** — Menampilkan berbagai resep makanan.
- 🔎 **Search Recipe** — Mencari resep berdasarkan nama makanan.
- 📂 **Recipe Categories** — Menampilkan resep berdasarkan kategori.
- 🌎 **Cuisine** — Menampilkan resep berdasarkan asal masakan.
- 📖 **Recipe Detail** — Menampilkan informasi lengkap mengenai resep.
- 📱 **Responsive Design** — Dapat digunakan pada berbagai ukuran layar.

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- REST API
- TheMealDB API

## 🔗 API

SAVORA menggunakan **TheMealDB API** untuk mengambil data resep makanan secara dinamis.

API yang digunakan:

`https://www.themealdb.com/api/json/v1/1`
